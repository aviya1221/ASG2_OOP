# Spike: form builder (F6)

Hands-on test for the tools report: can existing code give us the form builder and the answer window, at a reasonable cost to the page?

It bundles each option, measures what it adds to the page, and renders our own version for a form of the four question types (REQ-61).

## Run

```sh
npm install
npm start
```

See [results/summary.md](results/summary.md).
